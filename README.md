



#Instructions and Notes

1. Install Playwright -> `npx.cmd init playwright@latest`
2. check if installed correctly -> `npx.cmd palywright --help`
3. Run the test in all browsers -> `npx.cmd playwright test --headed`
4. Show the Report -> `npx.cmd playwright show-report`
5. Run the Test -> `npx.cmd playwright test`

**Push changes to Remote**
1. Git Commands
   - git init
   - git status
   - git add .
   - git commit -m "commit message" 
   - git branch -M main
   - git remote add origin <remote-url>
   - git remote -v
   - git push -u origin main
2. Issues
   - git config list
   - git push -f origin main -> force push
3. ACP - `Add commit push`
